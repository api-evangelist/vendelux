# Vendelux

> AI-native event marketing and B2B event intelligence platform. Vendelux helps go-to-market teams
> decide which conferences and trade shows to attend, pre-book qualified meetings before an event
> starts, and attribute pipeline back to specific events. It maintains a proprietary database of
> 250,000+ global B2B events enriched from first-party conference-organizer feeds and monitoring of
> 185,000+ sources, and syncs attendee, lead and ROI data into Salesforce and HubSpot.

Founded 2021 by Alex Reynolds and Stefan Deeran. Headquartered in New York City. Backed by FirstMark
Capital, Cervin Ventures, Tenacity Ventures and Tri-Valley Ventures.

## API status: none published

Vendelux publishes **no public developer API**. There is no OpenAPI, no GraphQL schema, no AsyncAPI,
no webhook catalog, no SDK, no CLI, no MCP server, no A2A agent card, and no developer portal or API
reference of any kind. This was established by direct probing on 2026-09-02, not assumed:

- `api.vendelux.com` is a real DNS record (Cloudflare-proxied) but returned HTTP 502 from its origin
  for every path probed, including `/openapi.json`, `/swagger.json`, `/graphql` and `/.well-known/*`.
- `developers.vendelux.com` is **not** a developer portal — it is a WordPress engineering blog
  (posts on recommendation systems, Snowflake, OpenAI embeddings). It returned HTTP 404 for every
  spec and `/.well-known/` path.
- The GitHub organization `github.com/Vendelux` exists but has **zero** public repositories.
- No package named `vendelux` exists on npm, PyPI, RubyGems, crates.io or Packagist.
- No pricing tier lists API access, an API key, or a call quota as a feature.

The only programmatic surface Vendelux sells is a CRM integration in which **Vendelux is the OAuth
client**, connecting outbound into a customer's Salesforce or HubSpot tenant. That is Vendelux
consuming someone else's API, not publishing one.

Vendelux's Terms of Service (§2.4, last updated 2024-02-07) further restrict automated access:
"use automated means, such as bots or crawlers, to access any Vendelux Technology or extract
information therefrom" is prohibited except via built-in Integration Tools or with prior written
approval.

## Product

- [Product Overview](https://vendelux.com/product): the full platform.
- [Event Discovery](https://vendelux.com/event-discovery): search 250,000+ B2B events for where a
  target ICP actually attends.
- [Meetings](https://vendelux.com/meetings): AI-assisted outreach to pre-book conversations before
  an event.
- [Segments](https://vendelux.com/segments): dynamic prospect and customer lists filtered by role,
  title and event attendance.
- [CRM Integration](https://vendelux.com/crm-integration): Salesforce and HubSpot connection for
  attendee monitoring and event ROI attribution.
- [For Event Organizers](https://vendelux.com/event-organizers): the organizer-side surface.
